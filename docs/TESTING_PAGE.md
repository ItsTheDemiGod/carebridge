# "How we tested it" page (Phase 6d)

Route `/how-we-tested-it` (header link "Testing", landing teaser). Figures come ONLY from `frontend/src/data/testing.generated.json`, built by `python scripts/build_testing_page_data.py` (`--check` for staleness; `backend/tests/test_testing_page_data.py`). No number is typed into a string: strings (`scripts/p6d_testing.py`) carry `{placeholders}` filled from each entry's params.

**Source files read (all committed)**: `eval/results/dev-ollama-v1-normalised-v2/metrics.json` (extraction raw vs rules, invented values, flags, readiness), `eval/results/stress-v1/metrics.json` (verification stack), `eval/results/phase3e-dev-clean/metrics.json` (lines shown per language), `eval/results/phase4-dev-with-supplement/metrics.json` (safety layer), the live-run file `docs/smoke/phase6d_live.json` (JSON lines), `data/reference/formulary.json` (size of the shared medicine list, used in the limits text). Dates are the day each file was committed (`RUN_DATES`); the files carry no date.

**Entry fields**: id, group, label, value, unit (ratio or count), source, measures, data (+params), caveat, split, date, optional n/of. The page shows the data line once per group when all rows share it, else per row; F1 is named only in the "what this measures" column.

**Rules (Phase 7b write-up)**: the page has a held-out TEST section first (66 rows, `test` key of the generated file, pooled over the five conditions: 15 extraction measures x raw/after rules, 8 flag/readiness, 8 safety, 15 explanation, 5 operational), then the dev groups. Every test row: value, n of N, interval (Wilson or document bootstrap), the DEV value of the same measure where the committed `dev_vs_test` table has one (difference, plus icon and text when the dev value lies outside the test interval), measure, source path, split `test`, run date (from the committed audit copy of the log). No row is selected; per-condition detail is named under "also measured" with a pointer to `docs/FINAL_TEST_RESULTS.md`. The builder first verifies `eval/results/final-test-v1/SHA256SUMS` and refuses on any change. The "not yet run" notice only shows when `final_test.run` is false (never now).

**Files touched in the 7b write-up** (all strictly for the page): `scripts/build_testing_page_data.py`, `frontend/src/pages/TestingPage.tsx`, `frontend/src/styles/flow.css`, `scripts/p6d_testing.py` (two reworded strings), new `scripts/p7b_testing.py` + `scripts/add_phase7b_templates.py` (102 new `ui.testing.t.*` and limits strings, ta/hi draft_unreviewed, sheet `data/templates/review_sheet_phase7b_new.csv`).
