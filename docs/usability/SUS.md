# System Usability Scale (SUS)

Standard ten statements; the participant rates each from **1 (strongly disagree) to 5 (strongly agree)**. "System" means the CareBridge app they just used. Read aloud for readers who prefer.

1. I think that I would like to use this system frequently.
2. I found the system unnecessarily complex.
3. I thought the system was easy to use.
4. I think that I would need the support of a technical person to be able to use this system.
5. I found the various functions in this system were well integrated.
6. I thought there was too much inconsistency in this system.
7. I would imagine that most people would learn to use this system very quickly.
8. I found the system very cumbersome to use.
9. I felt very confident using the system.
10. I needed to learn a lot of things before I could get going with this system.

## Scoring (standard)
- Odd-numbered items (1, 3, 5, 7, 9): contribution = response minus 1.
- Even-numbered items (2, 4, 6, 8, 10): contribution = 5 minus response.
- Sum the ten contributions (0 to 40) and multiply by 2.5: the SUS score, 0 to 100.
- Worked example: all odd items 5 and all even items 1 gives (4 x 5 + 4 x 5) x 2.5 = 100; all items 3 gives 50.
- With five participants report each score and the mean as a formative indication only. Do not call a score "good" or "acceptable" from a benchmark; with n = 5 that would be a statistic this test cannot support.

Enter the answers in `sus_responses.csv` (columns s1 to s10).
